What it does

Everything your table rolls, on screen

1

Captures everyone's rolls

Auto-detects public rolls from every player — no special format to type. Private whispers and GM rolls are never shown.

2

Real 3D dice that match

The physical dice land on the exact value rolled. For advantage or disadvantage, both d20s roll and the right one is shown.

3

An overlay that looks good

The Arcane Plaque shows portrait, big total, roll name, dice breakdown, advantage badge, and crit / fumble labels.

4

Shared or per-player overlays

Each player gets a filtered overlay URL — perfect for individual scenes, separate cameras, or custom OBS layouts.

5

Per-player dice skins

Everyone picks their own texture, material, and colors. Preferences are saved and persist between sessions.

6

Server-side rules

Crit and fumble logic adapts to your game system — D&D 5e by default — with no need to reinstall anything.

7

Reasonable fallbacks

Dice engine, fonts, sounds, and confetti are bundled locally. If anything fails, you still get a clean plaque with the total.

8

Preview without OBS

Open any overlay URL in your browser and press T to cycle through fake rolls: normal → critical → fumble.

Setup

Up and running in two minutes

Three steps, no coding. Works in any Chromium or Firefox browser.

1

Install Tampermonkey

A free browser extension that runs the capture script on your Roll20 tab.

Chrome Firefox Edge Safari Other / tampermonkey.net
2

Install the capture script

With Tampermonkey installed, click below to open the install prompt and hit Install.

Install the userscript ↓

Or paste this URL into Tampermonkey → Utilities → Install from URL:

It's pre-configured for the hosted relay — no editing needed, and it auto-updates from here.

3

Open Roll20 & add the overlay to OBS

Launch your Roll20 game. An OBS Overlay panel appears (bottom-right) and creates a room for you. Copy its Overlay URL.

In OBS: Sources → + → Browser, paste the URL, set the size (e.g. 1920×1080) with a transparent background. Your rolls now pop on stream.

Want per-player overlays? Each player's URL is in the panel too — add one Browser source each.

No OBS handy? Try it right now

Open any overlay URL in your browser and press T to cycle through demo rolls: normal → critical → fumble.
