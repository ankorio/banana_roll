🎲 Roll20 → OBS Overlay

Show your Roll20 dice rolls live on stream. Three steps — about two minutes.

1

Install Tampermonkey

A free browser extension that runs the capture script on your Roll20 tab.

Chrome Firefox Edge Safari Other / tampermonkey.net
2

Install the capture script

With Tampermonkey installed, click below — it'll open the install prompt. Hit Install.

Install the userscript ↓

Or copy this URL into Tampermonkey → Utilities → Install from URL:

The script is built for __ORIGIN__ — it talks to this relay automatically, no editing needed. It auto-updates from here too.

3

Open Roll20 & add the overlay to OBS

Launch your Roll20 game. A 🎲 OBS Overlay panel appears (bottom-right) and creates a room for you. Copy its Overlay URL.

In OBS: Sources → + → Browser, paste the URL, set the size (e.g. 1920×1080), transparent background. Dice rolls now pop on stream.

Per-player overlay URLs are in the panel too — one source per player if you want them placed separately.
